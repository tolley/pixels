Flow:

Modified files:


- www/auth.php — removed PHP sessions entirely; login/verify now call jwtSetCookie(), logout calls jwtClearCookie(); verify errors redirect to login.php?error=...
- www/grid.php — replaced the session modal with a 4-line PHP JWT gate at the top; username is PHP-rendered server-side; logout is a plain <a href="logout.php"> link; all auth JS removed
- docker-compose.yml — added JWT_SECRET env var

Flow:
1. Go to grid.php → redirected to login.php if no valid JWT cookie
2. Login → JWT set as httpOnly SameSite=Strict cookie → redirect to grid.php
3. Sign up → check email → click verify link → JWT set → redirect to grid.php?verified=1 → toast shown
4. Logout link → logout.php clears cookie → login.php

Rebuild the container to pick up the Dockerfile changes: docker-compose up --build.
