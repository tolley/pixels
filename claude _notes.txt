Flow:
1. Go to grid.php → redirected to login.php if no valid JWT cookie
2. Login → JWT set as httpOnly SameSite=Strict cookie → redirect to grid.php
3. Sign up → check email → click verify link → JWT set → redirect to grid.php?verified=1 → toast shown
4. Logout link → logout.php clears cookie → login.php

---
To activate Google:
1. Go to console.cloud.google.com → Credentials → Create OAuth 2.0 Client ID
2. Add http://localhost:8080/oauth_google.php?action=callback as an authorized redirect URI
3. Fill in GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET in docker-compose.yml

To activate Apple:
1. In Apple Developer → Certificates, Identifiers & Profiles: create a Services ID (your APPLE_CLIENT_ID) and a Sign In with Apple key
2. Add http://localhost:8080/oauth_apple.php as a return URL
3. Download the .p8 key file and base64-encode it: base64 -w 0 AuthKey_XXXXXX.p8
4. Fill in all four APPLE_* vars in docker-compose.yml

Account linking: If a user signs in via Google/Apple with an email that already exists from email/password signup, the OAuth identity is automatically linked to that account — no duplicate users.
